# Voice Dataset Collector 0.2.0

Android-приложение для локального сбора речи. Исходный проект дополнен CPU-обработкой звука и непрерывным разбиением длинных записей. Модель Silero VAD остаётся встроенной; интернет для записи и обработки не нужен.

## Быстрый запуск

1. Откройте эту папку в Android Studio с поддержкой AGP 9.1.1. Выберите JDK 17, установите Android SDK 37 и выполните Gradle Sync.
2. Подключите Android-телефон (Android 7.0 / API 24 или новее), разрешите USB debugging и запустите конфигурацию `app`.
3. До START выберите «Очищенная копия WAV»; опционально включите нормализацию. Разрешите микрофон и уведомления.
4. После START оставьте около секунды фонового звука без речи, затем говорите. Оригиналы сохраняются всегда. Очистка выполняется после закрытия каждой части.
5. STOP завершает текущую часть и ожидает очередь очистки. После сообщения о сохранении откройте список записей или экспортируйте ZIP.

Сборка и проверки в PowerShell:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

В Linux/macOS:

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Первой сборке нужен интернет для Gradle и Maven; приложению после установки — нет. Java-путь конкретного компьютера в проект не зашит.

В итоговом архиве также лежит уже собранный универсальный debug APK: `artifacts/VoiceDatasetCollector-0.2.0-debug.apk`. Он предназначен для проверки, не для публикации. Ключ подписи отличается от вашей локальной сборки: если установка поверх старой версии не разрешена, соберите проект со своим прежним ключом. Перед удалением старого приложения обязательно экспортируйте датасет: Android удаляет app-specific файлы вместе с приложением.

## Что изменилось

- Сохранение оригинала и отдельной копии `clean/`: high-pass 70 Hz, ограниченное спектральное подавление постоянного фона; опционально нормализация пика до −1 dBFS с усилением не более +6 dB.
- Шумовой профиль оценивается по участкам с низкой вероятностью речи Silero. Если подходящей тишины не было, спектральное подавление пропускается, это отражено в JSON.
- Один WAV не длиннее 600 секунд. Продолжение не ждёт повторного срабатывания VAD. `conversation_id`, `part_index`, `offset_samples` связывают части.
- Исходные PCM-сэмплы на границе 10 минут не дублируются и не пропадают в программной сегментации.
- RMS, пик, DC offset и доля перегруженных сэмплов в метаданных; предупреждения о тихой записи, клиппинге и смещении нуля.
- Фоновая очередь очистки ограничена; при перегрузке сохраняется RAW, а обработка помечается `skipped_busy`.
- Защита от перезаписи файлов, восстановление собственных незакрытых RAW `.wav.part`, атомарная запись JSON, сообщение об ошибках и контроль места.
- Прослушивание оригинала/очищенной копии по нажатию на запись. Отдельная отправка очищенной копии из того же меню. ZIP содержит обе версии и метаданные.

## Файлы датасета

```text
recordings/YYYY-MM-DD/
  HH-mm-ss_SSS_<id>_p001.wav       оригинал PCM16 / mono / 16000 Hz
  HH-mm-ss_SSS_<id>_p001.json      метаданные одной части
  clean/
    HH-mm-ss_SSS_<id>_p001.wav     обработанная копия той же длины
  metadata.jsonl                 дневной индекс
```

Счётчики длительности/числа файлов учитывают только оригиналы. Объём включает обе версии. Время тишины 3/5/8/12 секунд можно менять во время записи; параметры обработки — до следующего START.

«Диалог» здесь означает непрерывную VAD-сессию до выбранного таймаута тишины. Это не семантическое определение разговора и не разделение по людям. Непрерывный разговор может занимать сколько угодно частей по 10 минут.
